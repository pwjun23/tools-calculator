# 이사 어디 — 2단계 지역 설정 설계

1단계(기반, `2026-10-15-where-to-move-foundation-design.md`) 다음 단계다. 사이트 이름을 바꾸고, 사용자가 전국의 유효한 시·군·구와 읍·면·동을 골라 여러 지역의 실거래를 보게 한다.

## 목표
- 서비스 이름을 **이사 어디**로 바꾼다.
- 사용자가 설정 화면에서 지역을 목록으로 고른다(시·도 → 시·군·구 → 읍·면·동 체크). 자유 입력은 받지 않는다.
- 한 사용자가 시·군·구를 **최대 5개**까지 고른다. 각 시·군·구에서 읍·면·동을 1개 이상 고른다.
- 새 시·군·구를 고르면 **지난 12개월** 거래를 바로 받기 시작한다.

## 범위 밖
- 주소 검색(카카오 로컬 API), 통근 시간(3단계), 공개(4단계).
- 단지 단위 선택. 동 단위까지만 고른다.

## 지역 목록 (법정동코드)
- 출처: 공공데이터포털 "행정안전부_법정동코드"(`1741000/StanReginCd/getStanReginCdList`). 키는 기존 `DATA_GO_KR_KEY`이고, 이 API의 활용 신청이 필요하다.
- `scripts/where-to-move/build-regions.ts`가 전체 자료를 받아 `lib/whereToMove/regions.json`을 만든다. 공개 자료라 저장소에 커밋한다. 행정구역이 바뀌면 다시 돌린다.
- 변환 규칙(순수 함수 `buildRegionTree`, 테스트 대상):
  - 폐지된 코드는 뺀다.
  - 10자리 코드에서 앞 2자리는 시·도, 앞 5자리는 시·군·구(국토부 `LAWD_CD`), 6~8자리는 읍·면·동, 9~10자리는 리다.
  - 읍·면·동은 리가 `00`이고 읍·면·동 자리가 `000`이 아닌 행이다. 이름은 주소의 마지막 단어다(예: `양촌읍`).
  - 시·군·구 이름은 시·도를 뺀 주소다(예: `김포시`, `수원시 장안구`, `서구`). 세종처럼 시·도와 시·군·구가 같으면 시·도 이름을 쓴다.
  - 읍·면·동이 하나도 없는 시·군·구(구가 있는 시 자체, 예: `수원시` 41110)는 뺀다.
  - 표시 이름(label)은 `시·도 약칭 + 시·군·구 이름`이다(예: `경기 김포시`, `인천 서구`). 약칭은 고정 표(서울·부산·…·경기·강원·충북·…·제주·세종)로 만든다.
- 모양: `{ sidos: { cd: string; name: string; sggs: { cd: string; name: string; label: string; dongs: string[] }[] }[] }`. 동은 가나다순이다.
- `lib/whereToMove/regions.ts`가 JSON을 읽어 `findSgg(cd)`, `isValidRegion(sggCd, dongs)`, `regionLabel(sggCd)`를 제공한다.

## 설정
- 스키마: `regions`는 1~5개이고 `sggCd`가 서로 겹치지 않는다. 각 지역의 `dongs`는 1개 이상이다. 스키마는 모양만 검사한다.
- 저장 액션은 스키마 다음에 지역 목록으로 다시 검사한다. 없는 시·군·구나 그 시·군·구에 없는 동이 있으면 `regions.<i>` 오류를 돌려주고 저장하지 않는다. `label`은 클라이언트 값을 버리고 `regionLabel`로 다시 채운다.
- DB에 이미 있는 설정(label `김포`)은 그대로 읽힌다. 다음 저장 때 `경기 김포시`로 바뀐다.
- 기본값은 그대로 김포 `41570`의 구래동·마산동·양촌읍이다. label만 `경기 김포시`로 바꾼다.

## 설정 화면
- 맨 위에 "지역" 섹션을 둔다. 지역 카드마다 label, 읍·면·동 체크박스, 삭제 버튼이 있다.
- 카드 아래에 시·도 선택 → 시·군·구 선택 → "추가" 버튼이 있다. 이미 고른 시·군·구는 목록에서 빠진다. 5개가 되면 추가 칸을 숨긴다.
- 새로 추가한 카드는 동이 모두 꺼진 상태로 시작한다. 하나도 고르지 않으면 저장 시 오류가 난다.
- 지역 오류(`regions`, `regions.<i>`, `regions.<i>.dongs`)는 해당 카드 아래에 보인다.
- 저장했을 때 새로 받기 시작한 시·군·구가 있으면 "새 지역의 지난 12개월 거래를 받는 중입니다. 몇 분 뒤 목록에 나옵니다."라고 알린다.

## 수집
- 새 표 `wtm_collect_log(sgg_cd text, ym text, collected_at timestamptz, primary key(sgg_cd, ym))`에 연월별 마지막 수집 시각을 남긴다.
- 마이그레이션은 기존 `wtm_deals`의 (sgg_cd, 계약 연월) 조합으로 이 표를 채운다. 그래야 김포의 기존 달이 "처음 받는 달"로 취급되지 않는다.
- 한 시·군·구를 받을 연월(순수 함수 `monthsToCollect(now, logged)`):
  - 최근 2개월은 항상 받는다.
  - 지난 12개월 가운데 로그가 없는 달도 받는다.
- **처음 받는 달**(로그 없음)의 거래는 `first_seen_at`을 계약일(KST 00시)로 넣는다. 이미 지난 거래가 새 거래 알림에 한꺼번에 섞이지 않게 하기 위해서다. 이후에 다시 받을 때 새로 생긴 거래는 지금처럼 `now()`로 들어간다. 이미 있는 행의 `first_seen_at`은 바꾸지 않는다.
- 공용 함수 `collectRegion(sggCd, keys, now)`가 위 규칙으로 받고, 달마다 upsert한 뒤 로그를 남긴다. 한 달이 실패해도 나머지 달은 계속 받고, 실패한 달은 로그를 남기지 않는다. 그래서 다음에 다시 받는다.
- 매일 Cron은 모든 사용자 지역에 대해 `collectRegion`을 돈다. 한 번 실행할 때 받는 "로그 없는 달"은 모두 합쳐 최대 36개로 제한한다(함수 시간 300초 보호). 남은 달은 다음 날 이어서 받는다.
- 설정 저장 액션은 로그가 하나도 없는 시·군·구가 있으면 `after()`로 응답 뒤에 `collectRegion`을 돈다. 실패하면 로그만 남기고, 다음 Cron이 이어서 받는다.

## 목록 화면
- 제목은 `이사 어디`, 부제는 지역마다 `label 동·동`을 ` · `로 잇는다.
- 거래에 `sggCd`와 지역 label을 붙인다. 동 필터 칩은 지역별 줄로 나눈다. 칩의 값은 `sggCd:동`이라 다른 시·군·구에 같은 이름의 동이 있어도 섞이지 않는다.
- 네이버 검색어는 `거래 지역 label + 동 + 단지명`이다.
- 컴포넌트 이름은 `GimpoBoard`에서 `DealBoard`로, CSS 파일은 `board.module.css`로 바꾼다.

## 이름 변경
- 메타 제목: 목록 `이사 어디`, 로그인 `로그인 · 이사 어디`, 설정 `설정 · 이사 어디`. 로그인 화면 h1도 바꾼다.
- 카톡 메시지 본문에 지역명이 들어가는 곳이 있으면 label을 쓴다.

## 오류 처리
- 법정동코드 JSON에 없는 지역이 DB 설정에 남아 있으면(행정구역 개편 등) 목록과 수집은 계속 동작한다. 설정 화면에서 저장할 때 오류로 알린다.
- 백그라운드 수집 실패는 `console.error`로 남기고 화면을 막지 않는다.

## 테스트 (가상 값)
- `buildRegionTree`: 폐지 제외, 리 제외, 시·도=시·군·구(세종), 동 없는 시 제외, label, 정렬.
- `isValidRegion` / 저장 검사: 없는 코드, 다른 시·군·구의 동, 정상.
- 설정 스키마: 0개·6개·중복 sggCd 거부.
- `monthsToCollect`: 로그 없음 → 12개월, 일부 있음 → 최근 2개월 + 빠진 달, 모두 있음 → 최근 2개월.
- 처음 받는 달의 `first_seen_at` 계산(`backfillSeenAt`).
- 동 칩 그룹핑(같은 이름 동이 두 지역에 있을 때).

## 계획 단계에서 더한 것
- **거래 키에 시·군·구 코드를 넣는다**(`41570|매매|...`). 여러 시·군·구를 받으면 같은 이름의 동·단지 거래가 한 키로 합쳐질 수 있기 때문이다. 마이그레이션이 기존 키 앞에 `sgg_cd|`를 붙인다. 마이그레이션 뒤 옛 코드가 수집하면 키가 겹치므로, 마이그레이션과 운영 배포는 같은 자리에서(Cron 시각 전) 한다.
- **카톡 첫 줄은 `[이사 어디 주간]`**이다. 지역이 여러 개라 한 label로 부를 수 없다.
- 법정동코드 API는 `flag=Y`로 현존 코드만 받으므로 폐지 코드는 API 단계에서 빠진다.
